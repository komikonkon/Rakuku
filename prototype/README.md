# Rakuku UI モック（プロトタイプ）

配色・トーンを**見比べて決める**ための静的HTMLモック。仮データで主要10画面を表示する。

## 見方

`prototype/index.html` をブラウザで開くだけ（ビルド不要・依存なし）。

- 上部ツールバーの**配色スイッチ**（Indigo / Green / Teal / Sunset）で全画面の配色が切り替わる。
- **ダーク/ライト**ボタンで明暗を切り替えられる。
- 端末フレームに S01〜S10 を並べて表示。

## 目的

- 要件定義で唯一未確定の **UIルック（基本カラー・トーン）** を、実際の画面イメージで決めるため。
- 確定した配色を、本実装の Flutter テーマ（ColorScheme）に反映する。

## 注意

- これはあくまで**見た目確認用のモック**。動作ロジック・遷移は含まない。
- 文言・サンプル英語表現は仮。レイアウトの細部は実装時に調整する。
